# Notesi
**(Notes)i** ist eine Notizen Webanwendung, mit welcher man ganz einfach als Benutzer Notizen erstellen und bearbeiten kann.
Es soll vor allem einen Überblick über die Notizen verschaffen.

## Hinweis
Dieses Repository ist ein persönliches Lernprojekt und befindet sich kontinuierlich in Entwicklung.
Die Struktur und Umsetzung können sich im Laufe des Projekts verändern, während neue Technologien und Konzepte ausprobiert werden.
Unter anderem wird Spring Web, Thymeleaf, ... genutzt.

Da es ein Übungsprojekt ist, nutze ich für den Code KI. Ich werde die Stellen nicht spezifisch kennzeichnen. Dennoch kann ich den gesamten Code erklären und weiß, welche Stelle im Code was macht.
